# spotidy-Dashboard
This project is an interactive Power BI dashboard built using the Spotify Top 50 World dataset. The dashboard analyzes global music trends, artist performance, song popularity, and listener preferences through visually appealing and interactive reports.

📊 Project Objective

The main objective of this dashboard is to:

Analyze worldwide Spotify music trends
Identify top-performing artists and songs
Understand factors affecting song popularity
Compare explicit vs non-explicit content
Visualize music trends over time
📁 Dataset Information

The dataset contains daily records of Spotify’s Top 50 global songs and includes:

Song rankings
Artist names
Popularity scores
Song duration
Album type
Release date
Explicit content information

Each row represents a song’s chart position on a specific date.
